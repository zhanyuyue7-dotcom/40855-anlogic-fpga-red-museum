# 构建与复现

## 环境

- Windows；Tang Dynasty 6.2.1 / 6.2.168116，支持 EG4S20BG256，并使用合法有效的本机工具许可证。
- Icarus Verilog 14.0 devel（本机验证包 20260804），`iverilog.exe`、`vvp.exe`。
- Python 3.12；桌面依赖版本见 `desktop/requirements.txt`。不用 Anaconda 默认解释器替代项目环境。
- GTKWave 可选，仅用于打开 VCD。Qt 测试使用 offscreen 模式，无须连接 FPGA。

在此审核目录根部运行：

```powershell
py -3.12 -m venv desktop/.venv
& ./desktop/.venv/Scripts/python.exe -m pip install -r desktop/requirements.txt
$env:QT_QPA_PLATFORM='offscreen'
./tools/test-integration.ps1 -PythonExe "$PWD/desktop/.venv/Scripts/python.exe" -IcarusBin 'D:/EDA/iverilog/bin'
& ./desktop/.venv/Scripts/python.exe -m unittest discover -s tests -p test_td_build.py -v
./tools/check-timing.ps1 -ReportDirectory verification/frozen-build
```

本次实际运行借用本机已安装相同桌面依赖的独立 Python 3.12 环境，但测试的 RTL、脚本、参考文件和数据均来自这个审核目录。未复制该虚拟环境；评审机器按上述步骤建立自己的环境。

## TD 构建

```powershell
# 仅综合并检查资源
./tools/build.ps1 -Stage gate -PythonExe "$PWD/desktop/.venv/Scripts/python.exe" -TdExecutable 'D:/EDA/TD6.2.1/bin/td_commands_prompt.exe'
# 完整新构建；不删除旧结果
./tools/build.ps1 -Clean -PythonExe "$PWD/desktop/.venv/Scripts/python.exe" -TdExecutable 'D:/EDA/TD6.2.1/bin/td_commands_prompt.exe'
```

生成目录是 `build/runs/<输入哈希>-<时间>/`，状态入口是 `diagnostics/latest-build.json`。构建保留综合/布局/布线检查点；出现负 Setup/Hold 时拒绝 bitgen。构建完成后应对该次目录再运行 `tools/check-timing.ps1`，不要把已有 `bitstream/integrated.bit` 当作新构建输出。

`.al` 的 Project Path 保存原工作机路径以维持冻结输入一致性。构建入口会切换到本目录 `src/td_project` 并明确指定本地工程；工程内 File 引用已按本地相对路径检查。GUI 打开时也必须核对当前目录解析，不要误开原工作机的同名工程。若另存工程或修改路径，将产生新的输入哈希。

审核副本只给启动脚本增加 Python/TD/Icarus 路径覆盖，不改变硬件 RTL、约束和 IP。变更文件记录在 `verification/submission-audit.json`。冻结 `inputs.json` 中的历史工具驱动哈希代表当时的成功构建；不能宣称审核副本的启动脚本也与它逐字相同。

`verification/frozen-build/retry.tcl` 是成功物理重试的历史配方，含当时的工作目录和检查点路径。它用于追溯，不是可在任意机器直接执行的一键构建脚本；新构建使用 `tools/build.ps1`。只附 `final.db`，未复制所有中间 place/route 数据库。

## 上位机

```powershell
Remove-Item Env:QT_QPA_PLATFORM -ErrorAction SilentlyContinue
& ./desktop/.venv/Scripts/python.exe desktop/app.py
# 可选：由源码生成 EXE
& ./desktop/.venv/Scripts/python.exe desktop/build_windows.py all
```

串口采集需由操作者选择真实端口；网络操作需配置与当前 FPGA 静态 IPv4 匹配的可达地址。软件中的默认地址可能来自历史开发配置，不能只看默认输入框判断硬件地址。HXFP 图片端口是 UDP 5002；控制 UDP 5000 与 HTTP TCP 80 为独立功能。

## 数据、审计和波形

```powershell
# 按现有测试日志及冻结输入重算审核结果、历史统计和全文件哈希
& ./desktop/.venv/Scripts/python.exe tools/submission_audit.py
```

`submission_audit.py` 不会执行 TD 或板测，它检查已保存的结果。若要更新本次回归日志，应重新运行回归并把完整输出保存为 `verification/submission-regression.log`。历史原始日志不应重写。

波形复现命令见 `verification/waveforms/README.md`。`tools/` 中 `integrate_top.py`、`optimize_*.py`、`tune_roms.py`、`pipeline_sd_checks.py` 等是历史迁移/实验脚本，正常复现不运行，以免把已应用的修改重复应用。默认构建目标为 integrated；`baseline-src/` 仅用于明确的历史比较。

板卡下载使用匹配的 JTAG 工具；操作前核对目标器件、位流、配置方式与备份。当前位流及已有下载结果见 `验证结果与边界.md`。
