## 补充事项

1. **本地最终版本真实以太网图片端到端验证**：主机/RTL/本机 UDP 测试已具备，但不等同真实 W5500→SDRAM→HDMI 图片传输验收。
2. **原演示 TF 卡完整镜像及原视频/歌曲素材**：本审核目录不包含；不能仅复制 BMP 到任意 TF 卡就保证现有裸扇区布局相同。素材格式见工程接口说明。
3. **全工程干净重建的新增结果**：本次使用可追溯的最终成功构建文件，并检查源码哈希、工程引用与时序；没有另做一次 TD 全构建。脚本可复现，新运行会产生新身份。
4. **最终 RAR**：等待用户审核后生成，最终再核对实际压缩包小于 200,000,000 字节。当前目录体积见文件清单和审核结果。

工程附件包含源码、位流、约束、IP 依赖及验证记录，补充事项见上表及本节。具体板测要求按比赛验收规定执行。

代码附件不包含 Git 元数据、Python 虚拟环境、EDA 安装器或个人配置 Flash 备份。官方 IP 原文件及字体许可均保留。原始工作区的历史失败日志和其他候选位流未混入最终 `bitstream/`。
