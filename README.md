# 红色数字展馆｜瞬应逻辑队

基于安路科技 FPGA、利用以太网远程控制的红色文化多媒体展示系统，面向革命纪念馆、党群服务中心、校史馆等固定展项，也可用于教学演示与校园信息展示。

作品围绕“能展示、好操作、方便换内容”展开：板卡负责音画播放，手机网页负责日常控制，HX4S20 Studio 上位机负责图片处理、传输与运行状态采集。展示端以 HX4S20C 开发板上的 EG4S20BG256 为核心，连接 W5500 以太网模块、TF 卡、HDMI 显示器和本地输入设备。

## 主要功能

| 功能 | 说明 |
|---|---|
| 图片播放 | 从 TF 卡读取 640×480 BMP 图片，经 SDRAM 帧缓存输出，支持手动切图与自动轮播。 |
| 开场视频 | 连续读取预处理图像帧，将 320×240 素材进行 2×2 硬件放大，播放结束后进入轮播。 |
| HDMI 音画 | 输出视频与 48 kHz / 16 bit 立体声 PCM 音频，配合实时 FFT 频谱展示。 |
| 展示效果 | 支持淡入淡出、中文字幕、状态 OSD，以及四档亮度调节。 |
| 网页与本地控制 | 手机或平板通过局域网访问板端网页；本地按键、矩阵键盘与 UDP 接口共同接入场景控制。 |
| 场景调度 | 提供普通展示、提示与紧急场景，紧急事件优先显示。 |
| 配套上位机 | HX4S20 Studio 集成照片预览、格式转换、HXFP 图片传输、UART 状态采集、CSV 导出和记录回放。 |

## 系统设计

- **帧边界更新**：图片完整写入空闲缓存后再切换显示，场景和亮度状态在帧边界生效。
- **音画通路复用**：开场视频复用图片写入通路，TF 素材经缓存与合成后送往 HDMI 输出。
- **网络与显示分工**：W5500 处理网络协议，FPGA 完成 SPI 访问、命令译码、事件调度与显示提交。
- **运行观测**：上位机分别管理控制、图片与遥测通道，存储看门狗提供局部异常恢复。

## 快速开始

- FPGA 工程：`src/td_project/HDMI1.4b_Transmitter_v1.0.al`；顶层模块 `top`，工具链 Tang Dynasty 6.2.1 / 6.2.168116。
- 提交位流：`bitstream/integrated.bit`。
- 桌面软件：按 [构建与复现](docs/构建与复现.md) 安装依赖后，运行 `desktop/app.py`。
- 接线与素材格式：[工程结构与接口](docs/工程结构与接口.md)。TF 卡按文档中的扇区布局准备，网络控制端与设备位于可达的局域网内。
- 当前桌面软件验证记录：32 项测试通过；各功能的验证范围见 [验证说明](docs/验证结果与边界.md)。
